## 🚀 Hướng Dẫn Đưa Website Lên GitHub Pages (Rất Đơn Giản)

1. Đăng nhập vào tài khoản **GitHub.com** của bạn.
2. Nhấn nút **New** (Tạo Repository mới), đặt tên ví dụ: `bs-nguyen-hoa` (chọn **Public**), rồi nhấn **Create repository**.
3. Nhấn vào dòng chữ **uploading an existing file**.
4. Kéo thả **toàn bộ các file và thư mục `images`** trong folder này vào khung tải lên của GitHub.
5. Nhấn nút màu xanh **Commit changes** ở phía dưới.
6. Vào mục **Settings** (Cài đặt của Repository) ➔ Chọn **Pages** ở menu bên trái ➔ Tại mục **Branch**, chọn `main` (hoặc `master`) ➔ Nhấn **Save**.
7. Đợi khoảng 1–2 phút, GitHub sẽ cấp cho bạn đường link website chính thức (ví dụ: `https://ten-tai-khoan.github.io/bs-nguyen-hoa/`).
